LITOS Control Interno

Herramienta privada de automatización y control operativo para un pequeño taller.

Qué hace LITOS

LITOS automatiza tareas internas relacionadas con la recepción de documentación de pedidos, la organización de archivos y la lectura asistida de fichas manuscritas.

La aplicación utiliza autorización de Google para acceder únicamente a las cuentas expresamente autorizadas por sus propietarios y ejecutar los procesos internos configurados.

Uso de servicios de Google

Según el proceso, LITOS puede utilizar Gmail para localizar mensajes concretos, Google Drive para organizar documentación y Google Sheets para mantener el registro operativo. Algunas fichas pueden ser procesadas mediante la API de Gemini para extraer información estructurada, con revisión humana cuando la confianza no es suficiente.

LITOS no se ofrece al público general. Está destinado a uso personal y a un número reducido de usuarios conocidos por el responsable del sistema.
