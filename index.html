ALCANCE DE LOS DATOS

Qué se muestra

Cada registro conserva el ID de trabajo, la fecha, el modelo, el material y las medidas reales. Las alturas terminadas descuentan 4 cm de escalón y tapa.

No se publican nombres, inscripciones, fotografías, archivos, especificaciones libres ni el enlace o ID del libro maestro.

PRIVACIDAD

Reglas de este proyecto

01

LITOS es el único nombre visible. El nombre comercial real no aparece en la web, el repositorio ni la URL.

02

El Sheet no se publica. Permanece privado; el panel solo recibe un conjunto limitado de campos operativos.

03

Los cambios se hacen en el libro maestro. El panel se sincroniza cada minuto o al pulsar «Actualizar datos».
