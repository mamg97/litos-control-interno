Política de Privacidad

Última actualización: 17 de septiembre de 2026.

LITOS Control Interno es una herramienta privada destinada a automatizar tareas operativas de un pequeño taller. No es un servicio destinado al público general.

Datos de Google a los que puede acceder

Cuando un usuario autoriza LITOS mediante Google OAuth, la aplicación puede acceder, según los permisos concedidos, a Gmail, Google Drive y Google Sheets. El acceso se utiliza únicamente para los procesos internos expresamente configurados: localizar correos concretos relacionados con pedidos, organizar sus archivos en Drive, mantener registros operativos en Sheets y procesar fichas de trabajo.

Cómo se utilizan los datos

Los datos obtenidos de Google se utilizan exclusivamente para ejecutar esas funciones operativas. Determinadas imágenes o documentos de fichas pueden enviarse a la API de Google Gemini para extraer información estructurada. Cuando la confianza de la lectura automática no es suficiente, el resultado se deja para revisión humana.

Almacenamiento y conservación

Los documentos y registros operativos permanecen principalmente en las cuentas de Google autorizadas, en Google Drive y Google Sheets. Las automatizaciones se ejecutan mediante GitHub Actions en entornos temporales. El diseño evita almacenar el contenido bruto de correos o documentos en el repositorio público y evita imprimir ese contenido en los registros de ejecución.

Los datos operativos creados o actualizados en Drive o Sheets se conservan hasta que el responsable del sistema los elimina conforme a sus necesidades internas. Las credenciales OAuth se almacenan como secretos privados de GitHub y pueden revocarse o eliminarse cuando dejen de ser necesarias.

Compartición de datos

LITOS no vende datos de usuarios, no los utiliza para publicidad y no los comparte con terceros para fines comerciales. Los datos solo se transmiten a los servicios técnicos necesarios para ejecutar la funcionalidad descrita, principalmente servicios de Google y la infraestructura temporal de GitHub Actions.

Uso limitado de datos de Google

El uso de información recibida de las APIs de Google se limita a proporcionar y mantener las funciones de LITOS descritas en esta política y se realiza conforme a los requisitos aplicables de uso limitado de los datos de usuario de Google.

Control del usuario

El usuario puede revocar en cualquier momento el acceso concedido a LITOS desde la configuración de seguridad de su Cuenta de Google. La revocación impide que las automatizaciones obtengan nuevos datos mediante esa autorización, aunque no elimina automáticamente documentos o registros previamente creados en Drive o Sheets.

Contacto

Para cuestiones relacionadas con privacidad o consentimiento puede utilizarse la dirección de asistencia indicada en la pantalla de consentimiento OAuth de LITOS Control Interno.
